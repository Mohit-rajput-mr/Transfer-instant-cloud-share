# How to read a candle (~99 s, 1080×1920) · educational

One candle = one slice of time → open / close → green (close above open) / red (close below) → wicks = high / low →
buyers vs sellers tug of war → long upper wick = rejection → stop loss (auto-sell) → stops pile under the last low →
a big player pushes price into them → stops become sell orders, chain reaction → bought cheap, snap back, long lower wick →
spoofing (fake orders) is illegal; stop hunting at obvious levels is common → tips. Ends "share it on Orbi Transfer, no login".
