# The washer: Hubble's blurry start (HD film, 9:16)

"Do you know one ordinary metal washer left the most famous telescope ever built half blind?" Hubble, launched 24 April 1990
by Discovery; a 2.4 m mirror polished smooth to ~10 nm, yet its edge was too flat by ~2,200 nm (~1/450 mm) → spherical
aberration. The cause: the test tool (reflective null corrector) had a lens 1.3 mm out of place; a technician had filled an
unexpected gap with an ordinary metal washer. December 1993 (STS-61): corrective optics (COSTAR, WFPC2). Orbi ending (new):
every file has its own passcode; 12 wrong tries and it locks itself.

- `OrbiTransfer-hubble.mp4`: 1080×1920, H.264 + AAC (≤ 45 MB). Build as in the other films (`hubble_sfx.py`).

## The telescope is NASA's own model
