# Hubble Space Telescope — USE THIS MODEL

NASA's own 3D model (NASA 3D Resources, "Hubble Space Telescope (A)", "free and without copyright"):
`media/kit/models/hubble/hubble-nasa-A.glb` (Draco, 5 textured materials). Credit: "3D model: NASA".
Model units: 525.5 = 13.2 m → scale ×0.02512. Loaded in three.js its long axis is +y (aperture door up), centred.
Materials: `hbltel_1/2/4` aluminised skin, `hbltel_3` solar arrays, `hbltel_wfc_1` instrument radiator. Rejected: the
untextured "(B)" variant (loose parts, no textures). NASA preview: `nasa_preview.png`. See hubble-film/source/story_a.js.
