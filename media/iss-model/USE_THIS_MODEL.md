# International Space Station — USE THIS MODEL

NASA's own 3D model (NASA 3D Resources, "International Space Station (ISS) (D) (IGOAL)", "free and without copyright"):
`media/kit/models/iss/iss-nasa-igoal.glb` (96 MB, Draco + WebP, 555 meshes, 588 named nodes: Cupola, Columbus, BEAM, AMS, …).
Credit: "3D model: NASA". 1 unit = 10.8 m (the truss is 10.09 units → 109 m): scale ×10.8 for metres. Truss along z, Earth side −y.
Loads in ~20 s in the renderer. Rejected: NASA's "(A)" and "(B)" ISS models (flat colours, toy-like). NASA preview: `nasa_preview.png`.
