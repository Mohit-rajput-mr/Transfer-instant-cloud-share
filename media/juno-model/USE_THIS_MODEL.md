# Juno — USE THIS MODEL

NASA's own 3D model (NASA 3D Resources, "Juno (A)", "free and without copyright"): `media/kit/models/juno/juno-nasa-A.glb`
(Draco, textured: arrays, foil). Credit: "3D model: NASA". Units ≈ metres (each solar arm ~9 m). Dish on top (+y); arms in the
x–z plane, the magnetometer boom on the +x arm. "Juno (B)" was not used.
