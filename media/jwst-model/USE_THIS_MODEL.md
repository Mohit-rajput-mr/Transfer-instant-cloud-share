# James Webb Space Telescope — USE THIS MODEL

NASA's own 3D model (NASA 3D Resources, github.com/nasa/NASA-3D-Resources, "free and without copyright"). Version (A),
1,600 meshes, Draco-compressed (`media/kit/models/jwst/jwst-nasa-A.glb`, use DRACOLoader). Credit: "3D model: NASA".

- Units: metres. Telescope boresight toward **+x** (primary mirror face at x ≈ 1.0, centre y ≈ 6.3), sunshield in the
  x–z plane (x −11.5 … 9.7, z ±7.39), Sun on the −y / −x side; bounds x −18.6 (solar array) … 9.7, y −0.8 … 11.2.
- Named groups: `James_Webb_Space_Telescopebatwing1/2` (mirror wings, hinge ≈ (1.0, 6.3, ±1.68), vertical axis),
  `…shield` (sunshield), `…mid_booms`. Materials named by type (mirror_blinn, pinkmli, silver_mli, blk_mli …).
- Preview from NASA: `nasa_preview.png`. See jwst-film/source/story_a.js for finishes and the deployment rig.
