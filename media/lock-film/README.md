# A password carved in metal (science film)
3D cutaway film on the kit (`source/`), tyre-film v2 quality. Pin tumbler lock: wrong key won't budge, right key turns →
cut in half: housing + plug → pin stacks (key pin, driver pin, spring) → shear line; with no key the drivers cross it →
key cuts lift the stacks as it slides in → every gap lands on the shear line → plug turns, cam pulls the bolt →
wrong key: one cut too shallow, its key pin crosses the line (off by under a millimetre) → 5 pins × several heights =
thousands of keys → Linus Yale Jr. 1860s, after his father's pin tumbler; ancient Egypt had wooden pin locks →
