# Mars Reconnaissance Orbiter — USE THIS MODEL

NASA's own 3D model (NASA 3D Resources, "Mars Reconnaissance Orbiter (MRO) (C)", "free and without copyright"):
`media/kit/models/mro/mro-nasa-C.glb` (Draco, textured: gold foil, black krinkle, arrays). Credit: "3D model: NASA".
Units ≈ metres (13.2 across the arrays; real 13.6 m). Arrays along x; the high-gain dish below/behind (−y/+z side).
Needs DRACOLoader. NASA preview: `nasa_preview.png`. Real image used with it: HiRISE's Phoenix descent (PIA10705, public domain).
