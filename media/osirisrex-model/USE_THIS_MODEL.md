# OSIRIS-REx — USE THIS MODEL

NASA's own 3D model (NASA 3D Resources, "OSIRIS-REx", "free and without copyright"): `media/kit/models/osirisrex/osirisrex-nasa.glb`
(Draco, flat materials: foil, bronze, black). Credit: "3D model: NASA". Scale ×0.18 → metres (arrays 6.2 m across). The sample
return capsule sits on top (+y). The TAGSAM arm is stowed and merged into one mesh: it cannot be extended without rebuilding it.
Rejected for Bennu: NASA's "1999 RQ36 asteroid" (smooth pre-arrival radar shape) — use real OSIRIS-REx images of Bennu instead.
