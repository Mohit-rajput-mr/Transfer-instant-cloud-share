# People samples

`men-women-5-styles.png`: the 5 body styles (low-poly white, low-poly + wire, smooth grey, smooth skin, low-poly colour), men and women.
Built from primitives in `humans.html` (`human(style)`, `?sex=m|f`): lathe-profile torso and limbs, joint balls, head, hair for women. Port `human()` into a film's `person()` to use it.
