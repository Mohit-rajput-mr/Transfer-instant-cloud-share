# Perseverance rover — USE THIS MODEL

NASA's own 3D model (NASA 3D Resources, "Mars 2020 Perseverance Rover", "free and without copyright"):
`media/kit/models/perseverance/perseverance-nasa.glb` (Draco, WebP/JPEG textures, 68 meshes, JPL logo and name plate on the body).
Credit: "3D model: NASA". Units = metres (3.1 m long, 2.7 m wide; real 3 m × 2.7 m), wheels on y = 0, mast toward +z.
Its KHR_materials_transmission glass renders black with the kit's post-processing → set transmission 0, transparent, opacity ~0.35.
Needs DRACOLoader (`kit/lib/jsm/libs/draco/gltf/`). NASA preview: `nasa_preview.png`.
