# What is a liquidity sweep? (84 s, 1080×1920) · educational

Stopped out, then price flies → liquidity = orders waiting → equal lows look like support, stops pile underneath
(sell-side liquidity) → a fund needs 1,000,000 shares, 40,000 for sale → sweep inside the candle: stops fire into
the fund's bids, filled, snap back → one candle: long wick under the lows, close back inside → breakdown (closes below)
vs sweep (closes back inside) → buy-side liquidity above equal highs → tip. Built on candle2-film.
