# Your bank card has no battery (contactless film, 116 s)
Suspense science film on the kit (`source/`). Beats: tap in a café → hidden wire loop → reader's field flips ~13 million
times a second → induction (like a toothbrush charger) → chip wakes, works a few cm away → answers by flickering its
load (no transmitter, like morse with a torch) → secret key never leaves the chip → key + amount + counter + random =
one-time code → bank: PAID → thief's recorded tap: DENIED → Orbi: locked on your phone, code never leaves it, near you,
12 tries, 30-minute burn.
