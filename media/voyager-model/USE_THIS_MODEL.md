# Voyager 1 — USE THIS MODEL

NASA's own 3D model (NASA 3D Resources, "Voyager Probe (B)", "free and without copyright"):
`media/kit/models/voyager/voyager-nasa-B.glb` (Draco + WebP textures, 3 materials: `tex_01` body/boom, `tex_02_AO` dish,
`tex_02_AO_dark` dish centre). Credit: "3D model: NASA". Units ≈ metres: the dish is 3.81 wide → ×0.971 = 3.7 m (real).
Loaded in three.js the dish faces +y; the magnetometer boom runs along +z. Needs DRACOLoader (`kit/lib/jsm/libs/draco/gltf/`).
Rejected: "Voyager Probe (A)" (flat untextured colours, toy-like gold struts). NASA preview: `nasa_preview.png`.
Real photo for checks: "NASA's Voyager Testing" PIA21737 (NASA/JPL-Caltech, public domain, Wikimedia Commons).
